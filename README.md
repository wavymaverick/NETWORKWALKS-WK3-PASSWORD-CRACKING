NETWORKWALKS-WK3-PASSWORD-CRACKING



Week 3 Cybersecurity Internship Project



Project Overview



This project documents my practical experience with password cracking and recovery using John the Ripper (JTR), Johnny, and NetworkWalks tools.



The exercise covered two practical modules focused on password hash extraction, password recovery, and wordlist-based password attacks.



Modules Completed



\- WK3-PM1: Password Cracking with John the Ripper (JTR) and Johnny.

\- WK3-PM2: Password Cracking with NetworkWalks Tools.



Tools Used



Tool| Purpose

John the Ripper| Password recovery

Johnny| Graphical interface for John the Ripper

NetworkWalks Hash Calculator| PDF hash extraction

NetworkWalks Password Cracker| Wordlist-based password recovery

Windows PC| Practical lab environment



Module 1: Password Cracking with JTR



Objective: Recover passwords from provided password-protected PDF files.



Activities Performed



1\. Worked with John the Ripper through its graphical interface, Johnny.

2\. Extracted password hashes from protected PDF files.

3\. Loaded the extracted hashes into the recovery tool.

4\. Performed password recovery attacks.

5\. Successfully recovered the passwords of all three provided PDF files.



Result: Successfully recovered all three PDF passwords.



Evidence: "View JTR Screenshots" (Evidence/WK3-PM1-JTR/)



Module 2: Password Cracking with NetworkWalks Tools



Objective: Explore password hash extraction and wordlist-based password recovery.



Activities Performed



1\. Opened the NetworkWalks Hash Calculator.

2\. Used it to extract a PDF password hash.

3\. Submitted the extracted hash to the Password Cracker tool.

4\. Observed the wordlist-based password recovery process.



Result: Successfully extracted and submitted the hash and observed the password recovery process.



Evidence: "View NetworkWalks Screenshots" (Evidence/WK3-PM2-NETWORKWALKS-TOOLS/)



Key Observations



\- Password-protected PDF files contain password-related hashes that can be extracted for authorized testing.

\- Password recovery tools can test password strength using wordlists.

\- Weak or commonly used passwords may be easier to recover.

\- Strong and unique passwords are essential for better security.



What I Learned



This practical exercise helped me move beyond theoretical cybersecurity concepts into hands-on application.



I gained experience with two different password recovery approaches and developed a better understanding of hash extraction, password recovery tools, and wordlist-based attacks.



Most importantly, I learned why strong, unique passwords are an important layer of personal and organisational security.



Ethical Considerations



All activities were performed as part of an educational exercise using provided practice files.



Password recovery techniques should only be used on files, systems, and hashes for which proper authorization has been granted.
